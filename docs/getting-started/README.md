# Getting started

Pick your loader: [Fabric](fabric.md), [Forge](forge.md), [NeoForge](neoforge.md), [Paper](paper.md).

minuit is a mod the player installs. Your mod depends on it and never bundles it (no `include`, no
`jarJar`). Every build is on Modrinth's Maven as `maven.modrinth:minuit:2.0.1+<mc>-<loader>`, for example
`maven.modrinth:minuit:2.0.1+1.21.1-neoforge`. Then read the [guides](../guides/README.md).
