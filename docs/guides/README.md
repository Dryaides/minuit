# Guides

One page per kind of work. Each starts with code you can paste.

- [Simple screen](simple-screen.md): a panel of widgets in a `MinuitScreen`.
- [Container screen](container-screen.md): a menu with slots in a `MinuitContainerScreen`.
- [HUD](hud.md): bars, panels and widgets drawn over the game.
- [Your theme](themes.md): register your look, with your own palette, as the "Default" card.
- [Press styles](press-styles.md): how tabs, toggle groups and the side rail show the pressed segment.
- [Popups](popups.md): popovers, dropdown lists and your own overlay.
- [Keybind field](keybind-field.md): a key binding editor.
- [Scroll boxes](scroll.md): the scroll rule.

The full component list is in [API.md](../../API.md); theme files are in [THEMES.md](../../THEMES.md).
